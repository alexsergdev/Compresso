# Compresso

Автономний пакетний компресор для macOS: відео, фото, музика та PDF — з чергою, пресетами й фоновим рендером.

## Що вміє

- **Пакетна обробка** — перетягніть файли або цілу папку, черга порахує розмір і час
- **Пресети** для відео (H.264, HEVC, Apple ProRes), фото (WebP, JPEG, PNG, HEIC, TIFF) та музики (MP3, M4A, WAV, ALAC, FLAC)
- **PDF** — розбиття сторінок на зображення й стиснення з профілями: «Точний» (без втрат), «Розумний», «Компактний», «Вручну»
- **Збірка фото в один PDF** — з вибором якості та копією оригіналу
- **Фоновий рендер** із паузою, сповіщеннями та системними діями після завершення
- **Автоматичні оновлення** з GitHub Releases

## Системні вимоги

macOS 14 або новіша. Universal 2: Apple Silicon та Intel.

## Збірка з коду

```bash
./build_and_install.sh
```

Скрипт компілює universal-бінарник, підписує застосунок, створює DMG та `Compresso.zip` для релізу.

## Публікація оновлення

```bash
./publish_release.sh --version 1.0.2 --notes "Що нового" --yes
```

Або через GUI-публікатор:

```bash
./Tools/Publisher/build_publisher.sh
open "Tools/Publisher/Compresso Publisher.app"
```
